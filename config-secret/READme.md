🚀 Day 41 – Kubernetes Hands-on Project: ConfigMaps & Secrets

As part of my DevOps learning journey, I completed a hands-on Kubernetes project focused on managing application configuration and sensitive information using ConfigMaps and Secrets.

🔹 What I learned and implemented:

Created Kubernetes ConfigMaps to store non-sensitive application configuration.
Created Kubernetes Secrets to manage sensitive information such as database credentials.
Injected ConfigMap values into Pods using environment variables.
Mounted ConfigMaps as volumes inside containers.
Injected Secret values into Pods using secretRef and envFrom.
Explored Base64 encoding and understood why it is not encryption.
Compared environment variables and volume mounts.
Learned how configuration updates are reflected inside running containers.

🔹 Technologies Used:

Kubernetes
YAML
kubectl
Docker / NGINX
ConfigMaps
Secrets

🔹 Key Takeaway:

ConfigMaps and Secrets help separate application configuration from application code, making Kubernetes deployments more flexible, manageable, and secure.
